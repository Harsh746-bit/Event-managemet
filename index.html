Project Overview

Centralizing Campus Event Management

CampusConnect is a single-page college event management platform built to bridge the gap between event organizers and students. Instead of relying on noisy chat groups or scattered notice boards, students can browse, evaluate, and register for campus activities from a single, organized interface.

Start Discovering

Single Source of Truth

Consolidates announcements from all engineering departments, academic committees, and registered clubs into a verified calendar.

Frictionless Registration

Streamlines participant registration using responsive modal forms, eliminating redundant paperwork and third-party links.

Fully Responsive Layout

Engineered using Bootstrap 5's responsive grid system to provide seamless usability on smartphones, tablets, and desktop workstations.
