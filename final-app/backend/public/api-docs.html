Events REST Endpoints
GET /api/events
Fetch all campus events from MongoDB Atlas with capacity, registered seats, and dates.
POST /api/events
Create a new campus event and save it directly into MongoDB Atlas.
PUT /api/events/EVT-1001
Update an existing event's capacity, venue, or schedule in MongoDB.
Passes & Registrations Endpoints
GET /api/registrations
Fetch all active student event passes from MongoDB Atlas.
POST /api/registrations Seat Reservation
Book a student ticket, decrement event seat quota, and generate pass in MongoDB.
Users & Diagnostics Endpoints
GET /api/users
List all users (Admin, Organizers, and Students) stored in MongoDB Atlas.
GET /api/health
Check server uptime, database status ('connected'), and Atlas shard host.
